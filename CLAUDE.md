# CLAUDE.md

## Project Overview

This project is a data engineering pipeline for downloading, processing, storing, and visualizing cryptocurrency market data from Tardis.dev.

The main objectives are:

- Reliable downloading of historical market data
- Data cleaning and normalization
- Efficient storage of large datasets
- Basic exploratory visualization
- Reproducible data preparation for downstream quantitative research

This project does not contain trading strategies or execution logic.
